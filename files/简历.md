**资源爬取平台**
  ~ Java开发&爬虫脚本开发
  ~ 2024年09月 - 至今

- **项目背景**：面对应用市场早期部分应用版本更新慢、后期保障海外TOP体验应用及商业化应用全上架等问题，构建高并发、高可用的分布式爬虫平台，保障应用资源的实时性与完整性。
*   **架构设计**：采用 **Access（接入）- Dispatcher（调度）- Agent（执行）** 三层解耦架构。Access 层统一接收业务需求；Dispatcher 层负责任务分发与负载均衡；Agent 层支持**异构节点执行**（网页爬虫线程节点 & 真机 Box 节点）。
*   **核心工作与技术亮点**：
    *   **分布式任务调度体系**：基于**生产者-消费者模型**实现了任务协调器与调度器，通过多线程并发处理，将海量爬取需求动态匹配至空闲 Agent 节点，解决了任务堆积与资源浪费问题。
    *   **高可用实时通讯机制**：设计并实现了 Dispatcher 与 Agent 间的 **WebSocket 长连接**通信方案。引入**双向心跳检测**机制，实现了对Agent状态的秒级监控，一旦节点掉线可在 **1分钟内** 自动感知并触发告警或任务重试。
    *   **高扩展性的策略设计**：针对不同渠道（Google Play/国内友商）的数据差异，设计了**策略模式/模板方法** 的资源转化器，实现了新渠道接入的**零侵入或低代码配置**，大幅降低了后续维护成本。
*   **项目成果**：成功接入多家主流渠道，支持每日百万级任务调度，除核心爬取业务外，架构的通用性通过了端侧资源收集等边缘业务的验证。
